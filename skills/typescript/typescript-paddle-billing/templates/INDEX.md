**Do not read a template to copy it.** The templates total 303.4 KB; reading one to retype it costs its tokens twice and risks changing behaviour the tests pin.

1. Copy with the shell, keeping the relative path (`cp`, `Copy-Item`). Nothing is gained by opening the file first.
2. Open a file only when its **Use** is `adapt`, or to look up one signature: search the file for the export (`grep -n "export"`) and read just that function.
3. `run` files: copy them and run them; open one only to port it to a project test runner. Never open `tests/fixtures/*`.
4. `recipe NN` files: copy only when that recipe is in scope. `test double`: copy it with the tests; never ship it in the app.
